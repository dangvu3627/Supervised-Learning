Supervised Learning

---

## About The Project

This is a project I made to learn supervised learning workflow, classification methods. Essentially, this served as an experimental ground for my learning process.

### Classification methods
* **[k-Nearest Neighbors]** -Prediction made based on closest neighbors' class.
* **[Naive Bayes]** - Prediction made based on Bayes rule.
* **[Logistic Regression]** - Prediction made based on a sigmoid function.
* **[Support Vector Machines]** - Prediciton made based on a hyperplane, I use linear SVM in this project.

### Prerequisites
Make sure you have Python 3.8+ installed. It is highly recommended to use a virtual environment.
```bash
# Create a virtual environment
python -m venv venv

# Activate it (Mac/Linux)
source venv/bin/activate

# Activate it (Windows)
venv\Scripts\activate
```

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dangvu3627/Supervised-Learning.git
   ```
2. Navigate to the project directory:
   ```bash
   cd repo_name
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
